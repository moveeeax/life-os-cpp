GitHub section: link your GitHub account from Account (an OAuth App of the site, the token sealed server-side), and the worker keeps a fresh list of your repositories, yours and your organisations', public and private. Three tabs (needs attention, all, archived), a filter by owner, a search over names and topics; a repository needs attention for failing checks, open Dependabot alerts, open pull requests, open issues, a public repository without a description, license or README, or no push for a year (archive it?), each rule mutable per repository with "Not about this", and a task can be made from any item. Module `github`, off by default (`GITHUB_ENABLED`); the OAuth App's `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET` and the seal key `GITHUB_TOKEN_KEY` in the Secret; the worker job `github_sync`.
