The API controllers share their field and request helpers instead of local copies: `Api::Fields` gains `patch_text`, `currency_code`, `kTimeRe`/`is_hhmm` and `day_param`, `RequestUtils` gains `zone_or_utc`, and the new `api/Caller.hpp` (`signed_in_user`, `permissions_of`), `api/LinkChecks.hpp` (deal, project, task and trip ownership) and `api/MediaSupport.hpp` (the Sounds and Wallpapers store guard, upload descriptor, size check and delete) replace the per-controller versions. The one-shot token write moved to `UsedTokenRepository`, the focus-and-task transaction to `repositories/now/FocusTask.hpp` (so `src/api` no longer includes `database/` and the `api -> database` edge is gone), and a trip's spends total to `Money::Summary::total_in`. Redundant presence checks before validators that already skip an absent or null field are gone; codes and messages stay as they were.
