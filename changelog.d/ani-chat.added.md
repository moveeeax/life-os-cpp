Ani's agent, phase 2: a chat with her on Now, for every user. The new button on her ledge opens a panel; a message (`POST /api/v1/ani/messages`, kept in `ani_turns`) wakes the user's agent pod if it sleeps, and the ani worker runs the turn in the job `ani_turn` and the page polls `GET /api/v1/ani/turns/{id}` for the reply. The agent reads the user's Life OS through eight read-only tools (the day, the agenda, task search, goals, habits, sleep, money of a period, food of a day): the worker calls the site's own API as the user with a five-minute token (`ANI_AGENT_API_URL`), so the module switches and permissions of the site apply and the pod holds no Life OS credential. One turn at a time per user, 60 an hour, within the month's token budget. The `/api/v1/ani/*` routes are no longer administrator-only.
