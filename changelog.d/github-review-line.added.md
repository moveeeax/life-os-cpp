The Sunday weekly review gets one line when GitHub is linked and a repository needs attention: "N repositories need attention: <the first two by last push>" (`github` in `GET /api/v1/today`, absent when nothing needs it). "Make a task" on a repository's attention item makes one task per repository and rule in Tasks (the title names the repository and the reason, the note carries the GitHub link); a second tap opens the task while it is open and makes a new one after it was closed or deleted.
