## Scripts (`scripts/`)

| Script | Purpose |
|---|---|
| `new-resource.sh` | Scaffold a FULL CRUD resource (domain + repository + controller + registry + openapi + test) per docs/CONVENTIONS.md; `--owned` scaffolds a per-user resource |
| `new-endpoint.sh` | Scaffold a single controller + registry row + optional test + optional OpenAPI patch |
| `new-job.sh` | Scaffold a module's job handler in `src/<module>/jobs/` and wire it into the module's `register_jobs()` (and that into `core/JobHandlers.cpp` for a first handler) |
| `new-module.sh` | Scaffold a feature-module master switch (config flag + `Core::<name>_enabled()` + compose, both charts, docs/CONFIG.md), wired like the habits and notes modules; handlers open with `API_MODULE_USER_GUARD` |
| `new-migration.sh` | Generate the next `NNN_<slug>.sql` |
| `new-react-page.sh` | Scaffold a section page on the glass shell from the kit (`SectionFrame`, `Placeholder`) + a lazy shell route in the manifest, optional query-key branch |
| `gen-exercise-seed.py` | Generate the exercise-library seed migration of the workout module from a pinned commit of yuhonas/free-exercise-db (a newer dataset goes into a new migration number) |
| `gen-openapi-json.sh` | Convert `docs/openapi.yaml` into the committed `tests/e2e/openapi.gen.json` that the e2e binary validates response bodies against (needs pyyaml) |
| `check-openapi-drift.sh` | Verify `Api::get_endpoints()` (src/api/Endpoints.hpp) ↔ `docs/openapi.yaml` (method, path) |
| `check-openapi-breaking.sh` | Verify `docs/openapi.yaml` is additive against the merge base with `origin/master` (`oasdiff breaking --fail-on WARN`: a removed path or operation, a required response property made optional, a tightened type or a removed enum value fail); `OPENAPI_BASE_SPEC` names a baseline file instead of git; exit 2 when oasdiff is missing (never a silent pass; the pin is in the `openapi-drift` CI job) |
| `check-openapi-gen-fresh.sh` | Verify the committed `tests/e2e/openapi.gen.json` is byte-identical to a fresh `gen-openapi-json.sh` run over `docs/openapi.yaml` (needs pyyaml; exit 2 without it) |
| `check-routes-registered.sh` | Verify every controller ADD_METHOD_TO route is in `Api::get_endpoints()` (symmetric to the OpenAPI drift check) |
| `check-test-buckets.sh` | Verify test suites sit in the right bucket — classified by DIRECTORY, fails on a suite-name clash across unit/integration |
| `check-version-sync.sh` | Verify `project(VERSION …)` in CMakeLists.txt, the helm image-tag pins (`helm/cpp-env/values.yaml` and the three `deploy/values-*prod.yaml`), the four `Chart.yaml` `appVersion` fields, `docs/openapi.yaml` `info.version` and the `frontend/package.json` + `package-lock.json` root versions all match the newest released CHANGELOG heading (`[Unreleased]` on top stays green) |
| `release.sh` | One-command release: folds `changelog.d/` fragments into `[Unreleased]`, retitles it to `## [<ver>] - date` (accepts a hand-retitled heading too), bumps every version point (CMakeLists, the helm tag pins incl. `deploy/values-*prod.yaml`, the four appVersions, `docs/openapi.yaml` `info.version` with `tests/e2e/openapi.gen.json` regenerated, `frontend/package.json` + `package-lock.json`); verifies with check-version-sync.sh, commits nothing |
| `assemble-changelog.sh` | Fold `changelog.d/<topic>.<type>.md` fragments into CHANGELOG's `[Unreleased]` (creates `###` sections in Keep-a-Changelog order, deletes consumed fragments); `--check` validates fragment format only, run by the gates job (`openapi-drift` in ci.yml); fragments themselves stay optional |
| `check-frontend-nginx-sync.sh` | Verify `frontend/nginx.conf` and the helm cpp-frontend ConfigMap agree on the proxied backend routes |
| `check-module-deps.sh` | Verify every cross-directory `#include` in `src/` is an edge declared in `docs/module-deps.txt`; hard-forbids `utils -> *`, non-entry-point includes of `core/Core.hpp`, and `webhooks -> email`; then Tarjan over the declared edges fails on any strongly connected component of size > 1 not covered by `docs/module-cycles-allowlist.txt` (and names an allowlist line no cycle needs any more) |
| `check-config-sync.sh` | Verify every config read in `src/` (`cfg.get<T>("path", "ENV", …)` + getenv) exists in `config/config.json` AND `config/config.sample.json` and is documented in `docs/CONFIG.md`; flags stale doc rows and stale helm env lines (exceptions: `docs/config-sync-allowlist.txt`) |
| `check-helm-render.sh` | Render the cpp-env umbrella with CI values and assert deploy-path invariants (ports, hosts, empty credential defaults); render the prod releases from `deploy/values-*prod.yaml` and assert the prod security floor (rate limit on and fail-closed, CSRF, idempotency, JWT, Secure cookies) |
| `check-selftest.sh` | Prove the gate scripts bite (the `check-*` gates + `assemble-changelog.sh --check`): plant known breakages in scratch copies, require each gate to fail AND name it (control-pass first, counted mutators, a no-op mutation is itself a failure; needs helm+yq; the oasdiff and pyyaml cases print a visible SELFTEST SKIP line where those tools are absent and the verdict counts them apart) |
| `prod-check.sh` | `make prod-check`: renders the production release (`helm/life-os-cpp` + `deploy/values-prod.yaml`) and asserts the floor on the rendered ConfigMap and Deployment env: auth on, cookies Secure + CSRF, limiter fail-closed, docs off, HSTS on, no public-path override, credentials only from a Secret |
| `lint-openapi.sh` | Spectral lint with project ruleset |
| `make-jwt.sh` | Mint a dev HS256 JWT (no Python/Node deps) |
| `smoke.sh` | curl through critical endpoints (health, traceparent, validation, metrics) |
| `bench.sh` | wrk benchmark with config presets |
| `bench-ci.sh` | CI/nightly benchmark orchestrator — emits the JSON github-action-benchmark reads (`wrk2bench.sh` converts wrk output; `bench-incremental.sh` measures warm rebuild times) |
| `env-check.sh` | Report unset `${VAR}` placeholders in config without defaults |
